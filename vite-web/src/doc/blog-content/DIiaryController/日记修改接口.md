## 简要描述
- 接口描述

## 请求url
- `http://ip:port/content/diary/update`

## 请求方式
- POST

## 接口权限
- `sys:diary:update`

## 请求参数
| 参数名       | 必选 | 类型    | 说明                        | 校验范围        |
| ------------ | ---- | ------- | --------------------------- | --------------- |
| diary_md     | 否   | String  | 日记内容                    | 无              |
| diary_date   | 是   | Date    | 日记日期                    | 无              |
| diary_status | 是   | Integer | 日记状态（1：发布 0：草稿） | 1：发布 0：草稿 |
